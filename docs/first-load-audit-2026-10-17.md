# 首屏加载修复与本地验收

本版将公开数据请求提前到图表库之前，并解除可选数据和图表库失败对活动内容的阻断。仅本地实现、验证和提交，未推送或部署。

## 修复内容

- 新增 `web/src/initial-data.js`，提前并行请求平台、活动、基础元数据、覆盖信息和会员目录；数据层只消费一次预取结果，后续刷新正常重查，显式刷新仍绕过缓存。
- 提前失败的请求保存错误结果，避免应用尚未启动时产生未处理拒绝。必要接口失败仍进入原有错误流程，可选接口失败不阻止活动显示。
- 首屏只等待平台、活动和基础元数据；覆盖信息与会员目录独立补齐。会员目录未就绪时保留资格待确认，覆盖信息未加载时不显示虚假的零信源。
- 附加信息返回后更新页面，但保留后台、正在编辑的表单、打开的浮层及滚动位置；旧附加请求不能覆盖较新刷新结果。
- ECharts 缺失时仅图表区域显示提示；活动列表、详情和日历当天列表仍可浏览，日历实例清理也允许图表库缺失。
- 测试夹具显式提供浏览器图表全局；相对日期的既有回归样例使用测试进程时区，消除本地零点附近的不稳定期望，不改变产品日期逻辑。

图表脚本仍同步加载，本版未将下载等待改为异步。没有浏览器性能录制或同条件前后耗时对照，不报告提速百分比。

## 验证范围

`tests/initial-data.test.ts` 使用真实预取脚本、数据层、页面模板和页面脚本，覆盖：提前发起请求、预取仅消费一次、后续重新请求、显式刷新、必要与可选接口失败、附加请求延迟及乱序返回、构建脚本顺序、图表缺失时列表和日历降级。

此前本地 HTTP 检查确认主页、预取脚本及公开接口返回 200，页面预取脚本位于 ECharts 之前。异常与慢请求场景使用可控 DOM/VM 回归，不等同于真实浏览器网络故障注入或移动端视觉验收。

本地公开快照没有生产采集运行记录时，最近采集显示为空不能单独判断为网站故障。
